# matias-lee.github.io
Matias Lee's personal website, built with [Quarto](https://quarto.org).

## Updating the site
1. Edit the `.qmd` files (Markdown).
2. Preview: `quarto preview`
3. Build: `quarto render` (writes the site into `docs/`)
4. Publish: `git add -A && git commit -m "Update site" && git push`
